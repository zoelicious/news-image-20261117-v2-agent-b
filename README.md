# The World in One Day — Tuesday 17 November 2026

One image that sums up 17 November's world news: 43 stories from 6 continents.
A single full-width lead — Trump's first Quad summit in Manila — a numbers strip,
a ranked Top Stories list, a world map with numbered pins, and the rest of the
day in two columns.

## Run it

```sh
python3 main.py
```

This renders `entry.png` (1024×1024, RGB, deterministic) from `main.py` alone —
no network, no external assets. Flags and the map are drawn from code.
